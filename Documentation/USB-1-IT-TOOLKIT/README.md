# USB 1 — IT-TOOLKIT

## Purpose

USB 1 is the everyday technician toolkit used when a Windows system is able to boot normally.

## Contents

- PowerShell troubleshooting and automation scripts
- Network troubleshooting tools
- Microsoft Sysinternals
- Windows software installers
- Driver reference folders
- Windows recovery command references
- Help desk documentation
- Ticket templates and example tickets
- Portable applications

## Major Tools

- Nmap
- PuTTY
- Wireshark
- Sysinternals Suite
- HWiNFO Portable
- Notepad++ Portable
- Google Chrome
- Mozilla Firefox
- 7-Zip

## Use Cases

- Network troubleshooting
- Windows system diagnostics
- PowerShell administration
- Software installation
- User support
- Driver troubleshooting
- Help desk ticket documentation
- General PC troubleshooting

## Workflow

1. Boot into Windows normally.
2. Connect IT-TOOLKIT.
3. Identify the reported issue.
4. Use the appropriate diagnostic or reference tools.
5. Apply the least-destructive fix.
6. Verify the issue is resolved.
7. Document the result.
